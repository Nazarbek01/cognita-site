# Cognita — prototype screens

Screens of the real website, captured from a test run (sample data, test mode: the AI texts are placeholders).
Desktop screens are 1440 px wide; phone screens are 390 × 844 at 2×.
They are used in the Figma prototype (ICT Endterm, Task 1) and in the LMS submission.

Order follows the user flow: home → get started → choose your path → profile (student or professional)
→ 30 statements → AI analysis → matches → why it fits → career details → roadmap → dashboard,
plus the careers explorer and opening a saved result by code.
